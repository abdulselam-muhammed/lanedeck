# Set up the project for selam-deck

The AI has to prepare three files so the dashboard can follow this project:
- `.selam-deck/project.md`: what the project is, its stack, default branch, and how to run and test it.
- `.selam-deck/map.md`: the project's work map, drawn as stages and steps with their states.
- `.selam-deck/glossary.md`: terms that only make sense in this project.

## Steps
- [ ] Copy the prompt below and send it to your AI.
- [ ] The AI writes project.md, map.md and glossary.md.
- [ ] Review the work map it drew and correct it (the last step: ticking it, or pressing "Setup done", archives this file).

## Prompt for the Claude Code plugin
```
/selam-deck:init
```
